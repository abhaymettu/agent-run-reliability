# Battery v1: a ceiling

384 runs, 24 tasks x 2 models x 8 occasions, complete and balanced, collected
2026-09-04 00:51 to 01:24 EDT. No timeouts, no harness errors.

sonnet passed 190 of 192 (0.990), haiku 183 of 192 (0.953). Twenty of the
twenty-four tasks were passed by both models on all eight occasions. Only four
tasks produced any failure at all, and only one of those, arith_running_balance,
separated the models (sonnet 8/8, haiku 1/8).

At that pass rate there is almost no variance to decompose, so the data cannot
answer the question the study asks. The battery was rebuilt harder rather than
analysed. These runs are kept because the ceiling is itself a measurement: a
task set assembled to look reasonable landed far above the range where a
pass/fail evaluation carries any reliability information.
