You are given numbers.txt, one positive integer per line.

Consider each integer n in the file. n qualifies if it is divisible by 3 OR
divisible by 5, but NOT both (that is, exactly one of "divisible by 3" and
"divisible by 5" is true — a number divisible by both, such as 15 or 45,
does NOT qualify, and a number divisible by neither does NOT qualify).

Count how many qualifying integers there are (counting repeated values each
time they occur), and sum their values (using exact integer arithmetic, not
floating point).

Write the result to modular_result.txt with exactly two lines:

count=<integer>
sum=<integer>

Both values must be plain integers with no decimal point, no thousands
separators, and no extra whitespace. Do not add extra lines.
