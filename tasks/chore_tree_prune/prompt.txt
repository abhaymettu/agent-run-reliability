The current directory contains a tree of files and a file "meta.json" at the
top level. "meta.json" is a JSON object mapping each file's path (relative
to the current directory, "/"-separated) to that file's age in days as an
integer. Every file in the tree has an entry in "meta.json"; "meta.json"
itself is not a tree file and has no age. Ignore any file or directory whose
name begins with a dot; it is not part of the tree and must be left alone.

Remove a file if any of the following conditions hold (a file is removed if
it matches at least one):

1. Its age (from meta.json) is greater than 30 days AND its extension (the
   part of its name after the last ".") is ".log" or ".tmp".
2. Its size on disk is greater than 5000 bytes.
3. Its extension is ".bak".

All other files must survive, unmodified, at their original path.

After removing files, remove any directory that no longer contains any
surviving file, directly or in a subdirectory (i.e. prune now-empty
directories recursively, bottom-up). Do not remove a directory that still
contains at least one surviving file anywhere beneath it. Never remove
"meta.json" itself.

When finished, write "report.txt" in the current directory with this exact
format:

    REMOVED: <count>
    <one removed path per line, sorted alphabetically, "/"-separated>
    SURVIVED: <count>
    <one surviving path per line, sorted alphabetically, "/"-separated>

("SURVIVED" here means files, not directories, and does not include
meta.json or report.txt.) End the file with a trailing newline.
