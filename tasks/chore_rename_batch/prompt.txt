The current directory contains a flat set of files. Each file's content
starts with a line of the form "SEQ: <n>" where <n> is a non-negative
integer. Ignore any file or directory whose name begins with a dot; it is
not part of this task.

Rename every file (in place, in the current directory) to:

    item_<n>.<ext>

where <n> is the number from that file's "SEQ:" line zero-padded to exactly
3 digits (e.g. 7 -> "007", 42 -> "042", 250 -> "250"), and <ext> is the
file's original extension (the part after the last "." in its original
name, without the dot repeated). Do not change file contents. When finished,
the current directory must contain exactly one file per original file, each
under its new name, and no files under their original names.
