The current directory contains one file, "archive.txt". Its lines are
divided into sections by boundary lines that are exactly "---SPLIT---"
(nothing else on the line). There are N sections, separated by N-1 boundary
lines (the file does not start or end with a boundary line).

1. Create a directory "chunks/" in the current directory.
2. For each section, in order starting at 1, write its lines (excluding the
   boundary lines themselves) to "chunks/chunk_NNN.txt", where NNN is the
   section's 1-based index zero-padded to 3 digits (e.g. "chunk_001.txt").
   Join the section's lines with newlines and end the file with a trailing
   newline. If a section has no lines, write an empty file (0 bytes) for it.
3. Write "chunks/index.txt" with one line per section, in order, of the
   form:

       chunk_NNN.txt <line_count> <first_line>

   where <line_count> is the number of lines in that section and
   <first_line> is the exact text of the section's first line. If the
   section has no lines, write the literal word "EMPTY" in place of
   <first_line> (so the line reads "chunk_NNN.txt 0 EMPTY"). Fields are
   separated by a single space; end the file with a trailing newline.
