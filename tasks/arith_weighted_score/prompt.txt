You are given records.csv with columns id,x,y,z (x, y, z are non-negative
integers).

For each record compute a weighted score:

weighted_score = 0.5 * x + 0.375 * y + 0.125 * z

Round each weighted_score to exactly 2 decimal places using round-half-up
(if the digit in the third decimal place is exactly 5, round the second
decimal place up; this is NOT Python's default round(), which can round
down in that case).

Select the 5 records with the highest weighted_score. If two or more records
have the same rounded weighted_score, the one with the lower id ranks higher.

Write the result to top_scores.csv with header exactly:

id,weighted_score

Then exactly 5 rows, one per selected record, ordered from highest score to
lowest (ties broken by lower id first). Format weighted_score with exactly 2
decimal places (for example: 59.63, 5.00). Do not add extra columns, blank
lines, or trailing whitespace.
