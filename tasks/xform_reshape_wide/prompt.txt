You have a file named measurements.csv in this directory in long format,
with header "id,attribute,value" followed by data rows. The same id can
have several attribute rows, and not every id has a row for every
attribute that appears in the file. Occasionally the same (id,
attribute) pair appears more than once, with different values, at
different points in the file.

Reshape this into wide format and write it to a file named
measurements_wide.csv in this directory, as CSV with a header row:

    id,<attribute columns...>

- One row per distinct id, sorted by id ascending (ordinary text sort).
- Attribute columns after "id", one per distinct attribute name found
  anywhere in measurements.csv, sorted alphabetically ascending.
- If an id has no row for a given attribute, leave that cell empty
  (write nothing between the surrounding commas).
- If an (id, attribute) pair appears more than once in
  measurements.csv, use the value from whichever of its occurrences
  comes LAST in the file (later row order wins), and ignore the
  earlier occurrence(s).
- Write each value exactly as it appears in measurements.csv (do not
  reformat or round it). Do not quote any field.
