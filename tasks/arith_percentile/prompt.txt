You are given measurements.csv with columns id,value (value is an integer
and may be negative).

Compute the 90th percentile of the value column using linear interpolation,
defined precisely as follows:
1. Sort all values ascending into an array v (0-indexed), with n = the
   number of values.
2. For a percentile p (0-100), compute the rank r = (p / 100) * (n - 1).
3. Let lo = floor(r) and hi = ceil(r).
4. If lo == hi, the percentile value is v[lo].
5. Otherwise, interpolate: value = v[lo] + (r - lo) * (v[hi] - v[lo]).

Using that exact same method, also compute the 25th percentile and the 75th
percentile, and compute the interquartile range as IQR = (75th percentile)
minus (25th percentile).

Write the result to percentile_result.txt with exactly two lines:

p90=<value>
iqr=<value>

Format both numbers with exactly 2 decimal places, rounded half-up (if the
third decimal digit is exactly 5, round the second decimal digit up), with
a leading "-" for negative values and no thousands separators (for example:
103.30, -4.50, 0.00). Do not add extra lines or trailing whitespace.
